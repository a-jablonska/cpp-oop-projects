# OOP Fundamentals in C++

A collection of foundational classes demonstrating encapsulation, input validation, friend functions, operator overloading, and composition:

* **`BankAccount` (`BankAccount.h` / `BankAccount.cpp`)** — Account balance management with deposit/withdrawal validation and interest calculation.
* **`Circle` (`Circle.h` / `Circle.cpp`)** — Geometric circle class with area/circumference calculation and overloaded `<<` operator.
* **`Trapezoid` (`Trapezoid.h` / `Trapezoid.cpp`)** — Geometric trapezoid supporting area/perimeter calculation and uniform dimension scaling.
* **`PointArray` (`PointArray.h` / `PointArray.cpp`)** — Manages a collection of 2D `Point` structs using `std::vector`.
